# 🗺 Roadmap

Funcionalidades planificadas para futuras versiones de XAMA-ONG Platform.

## ✅ Completado (v1.0)

- [x] Autenticación JWT con 5 roles
- [x] Módulo de inventario con FeFo
- [x] Módulo de familias y repartos
- [x] Módulo de voluntariado y cuadrantes
- [x] Módulo Nevera Solidària
- [x] Métricas de impacto y exportaciones (CSV, Excel, PDF)
- [x] Certificados PDF de voluntariado
- [x] Certificados PDF de donación (Ley 49/2002)
- [x] Portada pública con donaciones Bizum
- [x] Modo oscuro
- [x] SSG/ISR en la portada pública
- [x] Auditoría y papelera
- [x] Importación CSV de familias
- [x] Notificaciones de caducidad por email
- [x] Backups automáticos
- [x] CI con GitHub Actions
- [x] 32 tests automatizados

## 🚧 En progreso / próximos

### Q4 2026

- [ ] **PWA** (Progressive Web App) para check-in en móvil sin app nativa
- [ ] **App móvil** con React Native (opcional, si hay presupuesto)
- [ ] **Portal de donante** con Stripe para tarjeta
- [ ] **Modo oscuro** en la portada pública
- [ ] **Notificaciones Telegram** para alertas de caducidad
- [ ] **Gráficos históricos** de largo plazo en analítica
- [ ] **Multi-idioma** (catalán + castellano)

### Q1 2027

- [ ] **Panel de transparencia pública**: ingresos vs egresos por proyecto
- [ ] **Integración con WhatsApp Business API** para avisos a voluntarios
- [ ] **Optimización de rutas** para vehículos de recogida
- [ ] **Predicción de demanda** con ML (familias vs stock)
- [ ] **Firma digital** de contratos de voluntariado
- [ ] **Exportación** a sistemas contables (A3, Sage)

## 💡 Ideas a explorar

- **Blockchain** para trazabilidad alimentaria (¿realmente útil?)
- **Generación de informes con IA** a partir de los datos de la plataforma
- **Recomendaciones inteligentes** de cestas según composición familiar
- **API pública** para integraciones con otras ONGs
- **Mapas de calor** de zonas con más necesidad por barrio
- **Comunidad online** entre voluntarios y familias (con moderación)

## 📊 Priorización

Las funcionalidades se priorizan según:

1. **Impacto en la operativa diaria** de la ONG
2. **Esfuerzo de desarrollo** (bajo, medio, alto)
3. **Número de ONGs** que se beneficiarían
4. **Disponibilidad de colaboradores**

## 📅 Historial de versiones

- Modo oscuro y diseño consistente
